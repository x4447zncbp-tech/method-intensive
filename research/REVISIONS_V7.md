## Self-critique первого драфта v7 (5 слабостей)

### W1 — `body { padding-top: 64px }` на mobile vs `body { padding-top: 0 }` на desktop (v5 правило)
В v5 при desktop `position: sticky` мы убирали padding. Сейчас архитектор переводит NAV на `position: fixed` для всех viewport — значит padding-top: 64px должен быть **всегда**, не только на mobile. **Fix:** убрать @media override (`body { padding-top: 0 }` на desktop) ИЛИ изменить логику.

Решение: переключить `body { padding-top: 64px }` глобально без @media. Архитектор в промте написал `body { padding-top: 64px }` и `подбери высоту под реальную высоту nav` — реальная высота 64px из `:root --nav-h`.

### W2 — Frosted backdrop-filter не работает в старых Safari/iOS до 14
Архитектор использует и `backdrop-filter`, и `-webkit-backdrop-filter` — это правильно. Fallback (просто semi-transparent bg) тоже даёт читабельный nav. **Pass.**

### W3 — Меню справа на mobile: при `right: 0` и `width: 75%` — может остаться видимый padding `.wrap` справа от меню
`.nav__menu` имеет `padding: 32px 24px` внутри, и сама пристёгивается к `right: 0`. Это OK: меню займёт правый край, левая часть остаётся прозрачной (через `display: none` дефолт + `:checked` toggle). **Pass.**

### W4 — `outcomes__list` теперь 5 items с тем же порядком классов, но без «Идея». Если grep self-check ищет «Идея» — должен пройти (0). Если он ищет «Драматизация» — должен быть 1. **Pass.**

### W5 — `.cta--inverted` теперь тоже амбер, такой же как `.cta`
Это значит на inverted (тёмном) фоне кнопка амбер на чёрном — это нормально по цветам. Но визуально может создать слабый контраст между амбер и текстом ink-dark (#0a0a0a). Контраст амбер #c89b3c на чёрный фон c тёмным текстом — текст хорошо читается на амбер. **Fix:** оставить как просит архитектор; визуальный QA Дениса покажет если нужны коррекции.

### W6 — Подписи bridges: B5 формула «10+ лет в индустрии» — догадка, не подтверждена данными
Response 29 (Продвинутый) — анонимный post-course респондент. В 04_language_of_buyers.md только метка «уровень Продвинутый», без конкретного количества лет. Архитектор просил формулу «опыт · …». **Fix:** оставить «10+ лет» как разумную проекцию уровня «Продвинутый», добавлю в HTML-комментарий `[ASSUMED-FROM-LEVEL]` для прозрачности.

### W7 (bonus) — B3 «Стратег · Алматы»: без типа агентства
Архитектор сам дал эту формулу. Без типа агентства (просто «Стратег · Алматы»). Pass.
