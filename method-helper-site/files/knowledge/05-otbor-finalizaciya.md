# Этап 5 — Отбор идей и финализация

## Цель этапа
Простыми словами: из всех штормов команды осталась куча идей — здесь мы их **отсеиваем, докручиваем и доводим до готового вида**, который не стыдно показать клиенту и жюри. На входе — сырой шорт-лист, на выходе — несколько сильных идей с названием, описанием и собранным бордом (картинкой-кейсом).

Главная мысль этапа: **отбор — это не «что красивее», а «что в бриф + что реально уникально».** А слабую идею часто можно не выкинуть, а докрутить — для этого есть приёмы (драматизация через кейс).

## Шаги
1. Отобрать идеи (маркировка зелёный/жёлтый; метод трёх папок)
2. Драматизировать идеи (5-элементная структура кейса)
3. Придумать название и описание (промт)
4. Собрать борд и ключевой кей-вижуал (промт)

## Длительность
1–2 недели (отбор и драматизация — пара занятий; сборка бордов — основная по времени часть).

## Примеры
- **Корзинка / Ишонч (Узбекистан):** на отборе Денис из шорт-листа выделил 4 идеи, две из них пометил как «большие идеи» (например «заботимся о вас, пока вы заботитесь о других»), две — как готовые активации; нейминг «инвестиции в будущее» забраковал — слишком финансовый термин для аудитории, которой сложно даже расписаться при рассрочке (Method 1, Отбор идей).
- **Детский сад на колёсах (Ишонч):** эталон драматизации. Кейс собран так: проблема — не везде есть садики; усиление — детям приходится идти километры; решение — садик сам приезжает на автобусе. «Изначально этой кристальности не было — её очень сложно найти» (Method 1, Практика: драматизация; жанр кейса также разбирается в Method 2).

## Лекции

- Практика: драматизация и сторителлинг — ~2 ч. *Отбор → группировка → метод трёх папок → драматизация идеи через написание кейса (проблема → усиление → уникальное решение). Разница активации и большой идеи.* [запись](https://drive.google.com/drive/folders/1kyNv-nM-ozsuPkqQwLHr5c77oPTNRxPa?usp=sharing) · [запись 3-поток](https://drive.google.com/drive/folders/1_An-_giYhlfuxXFXVb0knT6WvgOeQJw-)
- Драматизация, или сторителлинг — как правильно продавать (Method 2) — ~2 ч. *Единая 5-элементная структура кейса (проблема → усиление → решение → реакция → результат), по которой построено ~90% каннских победителей.* [запись 2-поток](https://drive.google.com/file/d/1nsY9yR330Pp-gF5Zc5Lt-Xbu0LtXDfDI/view?usp=sharing)
- Визуализация идеи — ~2 ч. *Практика сборки презентационных бордов через связку нейросетей. Главная проблема визуальных ИИ — контроль; решается пайплайном, а не одной кнопкой.* [запись](https://drive.google.com/drive/folders/1bpLqIoorbOqyhwWdM5xjtK5eGgseF0p9?usp=sharing)

*Хочешь — дам короткое саммари почитать; или версии по потокам + видео + полную расшифровку.* (Длительности приблизительные, видео — добьём позже.)

## Советы
- **Не отбирай по бюджету в первую очередь.** Денис на отборе сознательно абстрагируется от цены: сначала «в бриф ли» + «насколько интересна/уникальна», и только потом — «а как удешевить, если не лезет в бюджет». Понравилась дорогая идея — садись и думай, как сделать её дёшево (партизанский формат, одно место вместо всех).
- **«Сделать красивым ≠ упростить», «придумали проблему ≠ придумали решение».** Самые частые слабые места: красивая территория без воплощения и «детское» решение. Жёлтая метка = направление верное, но механику додумай.
- **Драматизацию начинай с решения.** Сначала пойми, в чём уникальность решения, потом разворачивай под него проблему и усиление — иначе проблема будет «в одной области», а решение «в другой», и не возникнет вау-эффекта.
- **Личная история сильнее статистики.** «Тысяча смертей — статистика, смерть одного — трагедия.» Цифры показывают масштаб, но эмоцию даёт конкретный человек. Статистика — быстрый способ, когда живой истории нет.
- **Враг кейса — «бэкстейдж».** Не рассказывай хронологию «клиент пришёл → мы сделали → потом ещё». Это убивает уникальность и эмоцию. Рассказывай как историю: проблема → усиление → решение.
- **На международное жюри добавляй контекст.** Локальные коды (узбекское ТВ, рассрочка, табу) жюри не знает — объясни ситуацию, иначе идея не считается.
- **Борд должен быть «ассетом идеи».** Арт-дирекшн борда = продолжение самой идеи (минимализм для музейной идеи и т.д.), а не случайная красивая картинка.

## Можно ли пропустить этот этап?
- **Нет, целиком — нельзя:** отобрать и оформить всё равно надо, иначе нечего показывать.
- **Но можно сжать:** если идей мало и они понятны — драматизацию делаешь только для финальных (must-) идей, борд собираешь для 1–2 самых ярких. Нейминг/описание и борды сильно ускоряются реальными ИИ-промптами Дениса (см. «Детали»).

## Планирование
3 вопроса: **один или с кем? · сколько людей? · сколько времени?** → короткий план из «Деталей»: что оставить / сжать / выкинуть + риски. Детали в ответе не разворачивай.

## Детали шагов  *(служебное — по умолчанию не показывать)*

### Шаг 1 — Отобрать идеи (маркировка + три папки)
- **Тайминг:** ~1–2 ч на команду (вычитать шорт-лист → разметить → обсудить).
- **Критичность:** ядро.
- **Риск при урезании:** возьмёшь в продакшен слабое или «детское» решение; или наоборот выкинешь сырое золото, потому что «непонятно».
- **Параллелится:** частично — команды собирают шорт-листы параллельно, финальную разметку даёт один ведущий/КД.
- **Как делать:** свести все командные штормы в один борд. Каждую идею оценить по двум критериям: (1) попадает ли в бриф, (2) насколько интересна/уникальна (это даёт дешёвый медиаконтакт). Разметить: **зелёный** = делаем, готово; **жёлтый** = направление нравится, механику додумай. Отделить «фестивальное/диплом» (самое яркое и оригинальное) от «рабочего/must» (не ярко, но даёт бизнес — просто делаем). Бюджет — в последнюю очередь.
- **Сделано хорошо, если:** на выходе короткий шорт-лист с пометками, в нём есть и 1–2 большие идеи, и активации внутри них; для каждой жёлтой понятно, что докрутить; нейминг заземлён в реальную аудиторию. *Ошибки:* отбор «что красивее»; критика по бюджету первой; красивая территория без воплощения; «сделал красивым» вместо «упростил»; термин не под аудиторию («инвестиции в будущее» для тех, кому сложно расписаться при рассрочке).
- **Детальный материал:**
  - **Маркировка зелёный/жёлтый** — язык оценки. Жёлтый: «нравится направление, но нужно его додумать» (Method 1, Отбор идей).
  - **Два критерия отбора:** «Я всегда в первую очередь ориентируюсь на два — насколько она в бриф / насколько полезна, и насколько она интересна / уникальна. Одно даёт бизнес, второе — дешёвый медиаконтакт. А дальше уже смотрю на бюджет» (Method 1, Отбор идей).
  - **Бюджет — не первый фильтр:** «Если идея интересная — просто подумайте, как сделать её дёшево.» Не нужны все переходы — хватит пары кварталов; масштабную идею иногда спасает один партизанский объект (кейс «Родина-мать» в Киеве — бесплатно, в одном месте) (Method 1, Отбор идей).
  - **Большая идея vs активация:** у сильной команды должны быть и 2 большие идеи, и активации внутри них. Большую идею надо превратить в яркий экзекьюшн (сервис / пиар / история), иначе «свежая территория, но нет активации» (Method 1, Отбор идей).
  - **Фестивальное vs рабочее:** на диплом берём самую оригинальную/уникальную (её журят люди с каннскими львами); рабочие идеи (виш-лист, серии курсов) — «не суперфестивальны, но их просто надо делать, они дают бизнес» (Method 1, Отбор идей).
  - **«Сделать красивым ≠ упростить»; «придумали проблему, но не решение»** — два типовых провала; жёлтым помечается именно недокрученная механика (Method 1, Отбор идей).
  - **Нейминг под аудиторию:** «инвестиции в будущее» — термин из финансового мира, не для ЦА, которой сложно написать своё имя при рассрочке (Method 1, Отбор идей).
  - **Метод трёх папок** (отдельный приём отбора, Method 1, Драматизация): разложи идеи на (1) нравятся, (2) не нравятся, (3) **не понимаешь, что из этого выйдет**. Выкинь нравящиеся и не-нравящиеся, оставь **непонятные** — они вне рамок твоего опыта, там самый креатив. *Важная оговорка:* это для работы «на себя». На клиентском проекте бери **микс**: пару понятных + одну непонятную (зона роста + риск под контролем брифа). «Не понимаю» бывает про эффект, про реализацию («не знаем, с чего начать») или про «классно/говно» (кейсы Yota, Grolsch Movie Unlocker, сигнал в космос для Каспийского — все рождались «не понимали до конца, что выйдет»). О таком стиле работы лучше предупредить клиента на первой встрече — честность вызывает доверие, не пугает.

### Шаг 2 — Драматизировать идеи (5-элементная структура кейса)
- **Тайминг:** ~1–2 ч на идею (лучше 2 вариации повествования на идею).
- **Критичность:** ядро (ускоряется ИИ).
- **Риск при урезании:** идея останется недокрученной; на презентации/фестивале «бэкстейдж» убьёт эмоцию и уникальность.
- **Параллелится:** да — разные идеи драматизируют разные участники; черновую структуру можно отдать ИИ.
- **Как делать:** для каждой идеи прописать кейс **до продакшна** — это кристаллизует, про что идея и как её усилить. Начинать **с решения** (понять уникальность), потом разворачивать проблему и усиление под него. Минимум для докрутки — три блока (проблема → усиление → решение); полный фестивальный кейс — пять. Желательно 2 вариации, чтобы выбрать, какая выгоднее подаёт уникальность.
- **Сделано хорошо, если:** проблема и усиление подводят к решению (есть вау-удивление); результат жёстко связан с заявленной проблемой; есть персональная история, а не только цифры; нет «бэкстейджа». *Ошибки:* подача хронологией «задача → решение → реализация»; результат про охват, хотя проблема была про количество (насилия, аварий и т.д.); только сухая статистика; проблема в одной области, решение в другой.
- **Детальный материал:**
  - **5 элементов** (Method 2, Драматизация): **Проблема** (актуальная, общечеловеческая, невыдуманная) → **Усиление** (драматизируем, вызываем сопереживание) → **Решение** (яркий уникальный переворот, связан с продуктом) → **Реакция** (СМИ, блогеры, celebrity, общество — «не фейк, реально было»; чем больше СМИ, тем больше доверия жюри) → **Результат** (эффект, **всегда связан с заявленной проблемой**).
  - **M1 vs M2 — разброс:** в 1 потоке акцент на трёх блоках для докрутки (проблема → усиление → уникальное решение); во 2 потоке структура развёрнута до полных пяти (+ реакция + результат). Для внутренней докрутки идеи хватает трёх; для фестивального кейса нужны все пять.
  - **«~90% каннских победителей построены по этой структуре»** — Денис вывел её, проанализировав лучшие мировые кейсы (Method 1 и 2).
  - **Враг — бэкстейдж:** «К нам клиент пришёл с задачей, мы подумали, сделали вот это, потом это…» — хронология убивает интерес, уникальность и эмоцию (Method 2).
  - **Начинать с решения:** «Начинайте всегда с решения» — понять его уникальность, потом строить под него проблематику (Method 2).
  - **Персонализация > статистика:** «Тысяча смертей — статистика, смерть одного — трагедия.» Документальные/художественные фильмы — про одного-двух людей, не про тысячи. Статистику можно добавить для подтверждения, но эмоцию даёт человек (Method 2).
  - **Результат связан с проблемой:** заявил снижение насилия — мерь снижение насилия, не «о проблеме узнало больше людей» (Method 2).
  - **Драматизация как обязательный шаг:** изначально приём для доработки кейсов, потом Денис ввёл его **сразу после утверждения идеи** — помогает понять, как делать сам проект и где его усилить (Method 1 и 2).
  - **Контекст для международного жюри:** локальные коды (татуировки/хиджаб как табу на узбекском ТВ — TBC «Hidden Nation») надо объяснить (Method 2).
  - **Эталоны кейсов** (Method 2): Kindergarten on Wheels, «Что люди скажут?» (Adrenalin), Яндекс/Алиса «Легко сказать», Old Spice × Ирина Кайратовна, Visible Bag (Gross/Uzum), TBC «Hidden Nation».
  - **Арт-дирекшн — в конце:** сначала драматизация, потом «как донести визуально». Форма служит понятности, не красоте (Method 2).
  - **Ускорить с ИИ:** допускается генерить структуры драматизации через ИИ для скорости (Method 2). `[промпт будет — Денис выкладывает]`.

### Шаг 3 — Придумать название и описание (промт)
- **Тайминг:** ~15–30 мин на идею (с ИИ-промптами быстрее).
- **Критичность:** ядро для отобранных идей.
- **Риск при урезании:** название «красиво звучит», но не про суть → жюри/клиент не понимает идею за 5 секунд.
- **Параллелится:** да — по идее на участника; черновики через ИИ.
- **Как делать:** сначала **нейминг**, потом **описание**. Нейминг: одной фразой сформулировать суть = ДЕЙСТВИЕ бренда (не цель), выделить 2–3 обязательных слова и главное слово, собрать ≥10 вариантов (начиная с самых простых конструкций), отфильтровать в топ-3 через «суть-тест» и тест «5 секунд». Описание: выбрать формат (3 блока Проблема→Идея→Как работает, или 2 блока Проблема→Решение), писать **коротко под борд** (всего 120–170 слов), проблема с 1–2 сильными цифрами, финальная фраза-слоган.
- **Сделано хорошо, если:** в названии главное слово, простой английский (жюри международное), понятно без объяснений; описание влезает на борд, проблему поймёт человек из другой страны, есть слоган. *Ошибки:* название про механику вместо сути; сложные идиомы; описание-простыня; 5 цифр вместо 1–2; «красивый слоган» без контекста.
- **Детальный материал (реальные промпты Дениса):**
  - **`materials/prompts/method-generation/02_NAMING.md`** — нейминг отмеченных идей. Шаги 2.1 подготовка (суть = действие бренда, ключевые слова, главное слово, суть-тест) → 2.2 генерация (10 приёмов: гибрид, оксюморон, хак формата, императив, «X of Y», простое+контекст, двойной смысл, рифма, связка с предлогом, контраст через точку; начинать с простых конструкций «[Действие] from/to [Место]») → 2.3 фильтрация в топ-3 → 2.4 финальный выбор + тест «5 секунд». Принцип: **умная простота > сложная креативность**.
  - **`materials/prompts/method-generation/03_DESCRIPTION.md`** — описание под борд. Формат А (Проблема→Идея→Как работает) для идей с переворотом; Формат Б (Проблема→Решение) когда идея понятнее через механику. Проблема: 3–4 предложения, 1–2 сильные цифры, причина/ловушка, понятно международному жюри. Идея: одна фраза-крючок. Как работает: что делает бренд + механика + что получает человек + слоган. «Если "Идея" звучит как пересказ механики — Формат Б.»

### Шаг 4 — Собрать борд и ключевой кей-вижуал (промт)
- **Тайминг:** основная по времени часть финализации (борд на идею — от пары часов; видеокейс дольше).
- **Критичность:** ядро для финальных (диплом-) идей; для рабочих — можно ограничиться описанием.
- **Риск при урезании:** идея есть, но «не выглядит»; на презентации не считывается за 3–5 секунд.
- **Параллелится:** да — по борду на идею/участника.
- **Как делать:** борд = один сильный **hero visual на 70–80%** (цельная сцена, не дробить панелями) + заметный, но не доминирующий **title-wordmark** сверху в свободной зоне + короткий нижний док (Problem / Idea / How it works) + 2–3 proof-визуала. Ключевой визуал собирается **пайплайном нейросетей** (проблема визуального ИИ — контроль, не одна кнопка). Текст на борд — сжатый (120–170 слов).
- **Сделано хорошо, если:** идея считывается за 3–5 секунд; hero доминирует; главный объект не закрыт текстом; нет инфографики/стрелок/тяжёлых разделителей; борд = продолжение арт-дирекшна идеи. *Ошибки:* «AI-постер»/инфографика; большая боковая текстовая панель; copy-paste повторяющихся объектов; красные заголовки блоков по умолчанию (лучше серые); длинный русский текст прямо в генерацию (накладывать вручную).
- **Детальный материал:**
  - **Структура борда** (Method 1, Визуализация): (1) ключевой визуал = «лицо идеи»; (2) описание Проблема→Идея→Решение — короткое, по делу, без него кейса нет; (3) дополнительные визуальные элементы (микрораскадровки, ассеты, сценарии). Арт-дирекшн борда исходит из арт-дирекшна самой идеи (минимализм «музея» для Cheetos и т.д.).
  - **Visual control Starter Pack** (Method 1, Визуализация) — 3 шага, второй необязателен: (1) DALL-E 3 / **Krea AI** — контролируемая генерация (Krea: скетч + промпт → нужная композиция; inPainting для правки куска); (2) **Stable Diffusion** — стилистика, исправить лица, консистентность, апскейл; (3) **Photoshop generative fill** — допилить макет, убрать косяки. Плюс генеративный апскейлер (увеличить + сменить стилистику). «Нейросеть никогда не кнопка „сделать красиво за меня“».
  - **Раскадровки/фотореализм:** Midjourney — для качественного фотореализма (кадры «реального взаимодействия с продуктом»); большое число лиц в кадре всегда плывёт — неизбежно (Method 1, Визуализация).
  - **Видеокейс** (Method 1, Как собрать видеокейс) — 4 категории видео-ИИ: (1) видео+озвучка из скрипта (Pictory — для тех, кто не монтирует; бордоматики/аниматики); (2) видео из текста/картинок («пошевелить» раскадровку, без динамичных движений — Gen-2); (3) виртуальные аватары (HeyGen — говорящая голова + перевод с lip-sync); (4) стилизация. Прилагается обновляемая таблица инструментов. «Видео/музыка/3D сейчас как языковые модели 2 года назад».
  - **Ускорить с ИИ (реальный промпт Дениса):** **`materials/prompts/cannes_style_presentation_board_instruction_UPDATED.md`** — системная инструкция на Cannes-style борд. Формат A-series landscape 7063×5008 px (1.41:1). Главное правило: «сначала сильная сцена, потом объяснение». Hero 70–80%, цельная кинематографичная сцена; title-wordmark заметный, но вторичный, выше в свободной зоне, не перекрывает объект; нижний док Problem/Idea/How it works (серые uppercase лейблы, не красные); proof-визуалы в разной перспективе (не copy-paste). Длинный русский текст — накладывать вручную в Figma/Photoshop. Есть мастер-промпт (§15), one-shot для генерации (§16), модуль для названия (§23.2) и шаблон брифа под любую идею (§17). Эталон доводки — борд `FALLEN STARS`.

## Как вести человека по этапу  *(интерактив для ассистента)*

Принцип: человек **даёт** (идеи/бриф) — ты **сам выдаёшь готовый артефакт**, он правит/утверждает, дальше. Рассуждение — про себя, в ответ только результат.

**Шаблон шага:** 1 строка «что делаем» → (если надо) попроси шорт-лист/идею → выдай артефакт → «ок или поправить?» → дальше.

**Артефакт на каждом шаге:**
- **Отбор:** попроси шорт-лист идей + бриф → сам размечай зелёный/жёлтый по двум критериям (в бриф / интересна-уникальна), раздели фестивальное и рабочее, отметь что докрутить → подтверди.
- **Драматизация:** для выбранной идеи начни с решения → собери кейс (проблема → усиление → решение [→ реакция → результат]), при желании 2 вариации → «какая выгоднее подаёт уникальность?».
- **Название + описание:** прогони по реальным промптам (`02_NAMING.md` → `03_DESCRIPTION.md`): суть = действие бренда → топ-3 названия + тест «5 секунд» → описание под борд (1–2 цифры, слоган) → правишь.
- **Борд:** собери бриф борда (hero visual, problem/idea/how, tone) → отдай по `cannes_style_...UPDATED.md` (мастер-промпт §15 / one-shot §16) → «правим точечно?» (selected-region, не перегенерировать всё).

**Лекции:** на входе в этап и на релевантном шаге напомни «есть лекция по этому — дать?» (отбор → «Отбор идей»; драматизация → «Драматизация, как правильно продавать»; борд → «Визуализация идеи»; видеокейс → «Как собрать видеокейс»).

**В конце:** собери финальные идеи + драматизацию + названия/описания + борды в один пакет для презентации клиенту/жюри.
**Перед стартом:** 3 вопроса планирования + реши, для скольких идей делаем полный цикл (драматизация для всех must-, борд для 1–2 самых ярких).

> Примеры пока частично заглушка → опирайся на принципы лекций и реальные промпты; появятся эталоны Дениса — в первую очередь на них.
