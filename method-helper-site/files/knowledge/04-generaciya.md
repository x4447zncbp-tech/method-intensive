# Этап 4 — Генерация

## Цель этапа
Простыми словами: на базе смыслов и направлений, выбранных на синтезе, придумать максимум идей — много и быстро. Главный фокус — не «сидеть и ждать гениальную идею», а собрать всё в один экран и системно её достать.

Главная мысль Метода: **идею нельзя выжать из пустого листа — её надо подготовить.** Если есть 10 часов на идею, 9 уходит на изучение и сборку брифа, и только час — на сам шторминг. Ступор почти всегда не от нехватки таланта, а от нехватки информации.

## Шаги
1. Ресёрч по мемам, культуре, объектам — под выбранные направления
2. Собрать одностраничный бриф (One-Page Brief): текстовый и/или визуальный
3. Индивидуальный шторминг
4. Командный шторминг
5. Докрутка идей по трём вопросам

## Длительность
~1 неделя (ресёрч + 1–2 шторм-сессии + докрутка).

## Примеры
*(Денис добавит примеры — собранные брифы, борды со штормингом. Показывать по запросу: «показать пример?».)*
Сквозной кейс — велофонд Orange County: под выбранные направления собирали мемы про велосипедистов, знаковые объекты региона, велосипедную фактуру (как клеят имена на раму, разметка) → бриф → шторминг (Method 3, 016).

## Советы
- **Бриф собирай заранее, не штормь с нуля.** Без подготовки шторминг — как копать яму лопатой в случайном месте; с брифом — есть карта и инструменты, копаешь точечно (Method 2).
- **Полный оффлайн на индивидуальном шторминге.** Час без интернета и уведомлений. Нормальные мысли начинают приходить на 40–45 минуте — раньше не бросай (Method 2/3).
- **Не объединяй идеи.** Записывай много маленьких отдельно. Объединение под «большим интегрированным проектом» убивает одну из идей или делает обе средними (Method 1/2).
- **Конкретика рождает решение.** Пока ты на общих словах («сделаем финграмотным») — рождаются общие идеи, которые никого не цепляют. Уходишь в конкретный пример — тут же появляется решение (Method 2).
- **Можно ускорить ИИ.** Есть авторский промпт-движок Дениса, который из брифа (жёлтые × серые) сам гонит идеи батчами до ТОП-30. См. блоки «Ускорить с ИИ» ниже.

## Можно ли пропустить этот этап?
- **Нельзя пропустить целиком** — это сердцевина Метода. Но **облегчается**: при готовом синтезе и собранном брифе сам шторминг занимает час.
- **Можно сжать ресёрч** (шаг 1), если направление узкое и культурный материал уже есть с этапа исследования. Но без брифа (шаг 2) шторминг разваливается — это не урезается.

## Планирование
3 вопроса: **один или с кем? · сколько людей? · сколько времени?** → короткий план из «Деталей»: что оставить / сжать / выкинуть + риски. Детали в ответе не разворачивай.

## Детали шагов  *(служебное — по умолчанию не показывать)*

### Шаг 1 — Ресёрч по мемам, культуре, объектам (под направления)
- **Тайминг:** ~1–2 дня (большую часть Денис делает сам через ИИ).
- **Критичность:** можно сжать (но не выкинуть для больших идей).
- **Риск при урезании:** без культурного слоя идеи получаются «голыми», без эмоционального пласта; визуальный бриф собрать не из чего.
- **Параллелится:** да — мемы/объекты раздать по людям, технологии копить как базу насмотренности.
- **Как делать:** под уже выбранные направления собрать три вещи: (1) мемы/анекдоты/приколы по теме, (2) знаковые объекты и пространства региона (памятники, наружка, места), (3) фактуру вокруг самого продукта/темы. Складывать с визуальным подтверждением, не «из головы». Это сырьё для серых блоков визуального брифа.
- **Сделано хорошо, если:** под каждое направление есть набор мемов + объектов + предметной фактуры с картинками. *Ошибки:* собирать абстрактно, не под конкретное направление; брать «из головы» без пруфа; пропустить — и потом нечем наполнить визуальный бриф.
- **Детальный материал:**
  - Денис вслух про велобриф: «первое — мемы, второе — какие-то знаковые объекты, пространство, наружка и прочее. Третье — что-то связанное с велосипедом… как на велосипедах наклеивают имена, или дорога, или разметка — всё, что около-велосипедная история, с которой мы можем повзаимодействовать» (Method 3, 016).
  - Ищем «точки, притягивающие большое внимание» ИЛИ смыслово связанные с брифом; культурные события привязывать к локации брифа (Method 3, 016).
  - Весь сбор идёт «с сёрчем, с аишками» — большую часть Денис делает сам (Method 3, 016).
  - **Ускорить с ИИ:** есть авторский MD-промпт культурного ресёрча (поиск культурного напряжения), оптимизированный «под любую нейронку с учётом её памяти», сам аранжирует противоречия — `[промпт будет — Денис выкладывает]` (Method 3, 016).

### Шаг 2 — Собрать одностраничный бриф (One-Page Brief)
- **Тайминг:** ~0,5 дня (бриф алгоритмичен; черновик можно отдать ИИ).
- **Критичность:** ядро (без этого шаг 3–4 разваливаются).
- **Риск при урезании:** штормишь с нуля → мало идей, абстракции, выгорание. Это и есть «страх белого листа».
- **Параллелится:** частично — шаблоны общие, наполнение можно раздать.
- **Как делать:** собрать ВСЁ для шторминга на одном экране. Есть две вариации:
  - **Текстовый бриф** (структурнее, лучше для активаций): жёлтые стикеры = боли-цитаты из интервью + серые блоки = точки контакта/фичи/технологии + внизу три вопроса докрутки.
  - **Визуальный (фото-)бриф** (лучше для больших, глубоких идей): вместо серых блоков — картинки: культура/мемы, медиа, продукт, технологии.
- **Сделано хорошо, если:** на одном экране собраны 6–8 жёлтых болей (дословные цитаты) + серые блоки/картинки + три вопроса; названия идей хлёсткие, отражают суть. *Ошибки:* сокращать/обобщать цитаты вместо дословных; мало жёлтых (2–3) — нечего комбинировать; путать, какой бриф под какую задачу.
- **Детальный материал:**
  - **Структура серых блоков** (Method 3, 013): (1) сам продукт — диджитал или оффлайн (приложение и его фичи; для магазина — пакеты, чеки, кассы, этикетки); (2) популярные диджитал-сервисы (Яндекс.Карты, Spotify — то, чем люди пользуются); (3) медиа-сервисы по теме (блоги, инфлюенсеры, СМИ, газеты); (4) **блок «несвязанного»** — вещи, принципиально НЕ связанные с темой («ты намеренно пытаешься придумать что-то, что никак не связано» — даёт вырваться за рамки).
  - **Три вопроса докрутки** дословно (Method 3, 013): «как эту идею реализовать в приложении? как превратить в сервис/услугу? что добавить, чтобы попала в заголовки газет?». Последний (PR) — **must**, всегда оставлять, максимально докручивает идею. Вопросы можно менять под задачу (для ролика — «как это в драме / комедии / мультфильме»), но не больше трёх.
  - **Эволюция OPB** (Method 2): раньше брифы были 45–50 страниц — информация терялась, когда команда уходила штормить; раньше работали «на количество» (50 идей, одна выстрелит) — утомительно. OPB концентрирует всё в один экран.
  - **Два брифа — разные задачи** (Method 3, v2): «фото-бриф даёт больше — с фотографии считываешь обстановку, вещи»; НО «если ты сам аудитория, текст наталкивает на такие же глубокие ассоциации». В фото-брифе нет заголовка-сообщения — отталкиваешься от любой картинки.
  - **Ускорить с ИИ:** брифы алгоритмичны, грузятся в чат-бот. У Дениса есть промпт-движок генерации (`00_MASTER.md` + `01_GENERATION.md`): загружаешь бриф (N жёлтых × M серых) → ИИ батчами по 6 гонит идеи по каждому жёлтому, отбирает ТОП-20 → прогоняет через три вопроса (сервис / соцпроект / заголовки газет) → финал по жёлтому ТОП-15 → суперфинал ТОП-30 ранжированных. Принцип движка: «умная простота > сложная креативность», «суть = ДЕЙСТВИЕ бренда, не цель», бюджет не оценивать (`materials/prompts/method-generation/`).

### Шаг 3 — Индивидуальный шторминг
- **Тайминг:** ~1 час (полный оффлайн).
- **Критичность:** ядро.
- **Риск при урезании:** без личного оффлайн-захода идеи получаются «как у всех», нет багажа для командной встречи.
- **Параллелится:** да по определению — каждый штормит сам.
- **Как делать:** ровно час полностью в оффлайне, все уведомления выключены. Брать любой жёлтый стикер (боль) + любой серый (фича/картинка) и пытаться соединить. Не родилось за 1–2 минуты — переключайся на другую пару. Записывать ВСЕ мысли: одна мысль — один стикер, не объединять. Соединение несвязанного («доставка» + «театр») чаще рождает неожиданное.
- **Сделано хорошо, если:** на выходе — много отдельных стикеров с хлёсткими названиями; не одна «супер-интегрированная» активация. *Ошибки:* объединять идеи; долго думать «записать / не записать»; не дойти до 40–45 минуты, когда идут лучшие мысли.
- **Детальный материал:**
  - «Ваша главная цель — максимальное количество заходов и мыслей. Записывайте только готовые. Каждую идею, каждую мысль, каждую активацию отдельно, на отдельный стикер — так больше шансов раскрутить» (Method 3, v2).
  - «Не обмусоливать, записать-не-записать. Запишите, надо вам это или нет, решите потом» (Method 3, v2).
  - В фото-брифе можно отталкиваться не только от стикеров: «комбинируй как хочешь — мемы соединять с продуктом» (Method 3, v2).
  - Полноценные мысли приходят примерно на 40–45 минуте оффлайна (Method 2).

### Шаг 4 — Командный шторминг
- **Тайминг:** ~1–1,5 часа.
- **Критичность:** ядро (но требует предварительной командной сонастройки).
- **Риск при урезании:** без правил команды шторминг скатывается в критику и эго → генерация умирает.
- **Параллелится:** это сам по себе командный шаг.
- **Как делать:** приходить уже с багажом идей (с индивидуального шторминга). По очереди: каждый рассказывает по одной идее → команда выясняет, что автору в ней нравится больше всего → докручивает по трём вопросам → сразу записывает на новый командный стикер → переходит к следующей. Цель — НЕ критика, а докрутка чужих идей. Никаких оценок «классно/плохо» — только развивать мысль.
- **Сделано хорошо, если:** каждая идея обсуждена, докручена и зафиксирована на отдельном стикере; нет критики; команда работает по заранее проговорённым правилам. *Ошибки:* критиковать вместо докрутки; приходить без идей; давать оценки; объединять идеи в кучу.
- **Детальный материал:**
  - Два правила успешного шторминга (Method 2): (1) подготовка — нельзя штормить с нуля; (2) полное отсутствие критики — командной и внутренней. «Критика моментально убивает генерацию». Разделять момент придумывания и момент оценки.
  - **Командная сонастройка ДО шторминга** (Method 1/2): установочная встреча снимает ~80% конфликтов; когда команда проговорила ценности — уходит страх ошибки, рождается креатив. Ценности вытаскивают из конкретного проекта, где было комфортно (не придумывают), ранжируют попарно, превращают в ежедневные ритуалы/правила. «Ценности не оживают, пока не превращены в ритуал»; «коллаборация важнее соревнования — уникальные идеи рождаются, когда разные опыты складываются вместе» (Method 2).
  - Юмор/мемы перед задачей улучшают решение креативных задач — отсюда традиция анекдотов на штормингах (Method 1, ЭИ).

### Шаг 5 — Докрутка идей по трём вопросам
- **Тайминг:** ~0,5 дня (отбор шорт-листа + разбор).
- **Критичность:** ядро.
- **Риск при урезании:** сырые идеи так и остаются «зёрнышком» — не дал им развиться, выкинул или обобщил.
- **Параллелится:** частично — голосование за идеи раздать, разбор шорт-листа лучше вместе.
- **Как делать:** все идеи свести на борд (Miro). Отметить звёздочками те, что нравятся (звёздочка «спасает» идею в шорт-лист, даже если непонятно прописана). Отобрать шорт-лист. Каждую идею докрутить: найти ядро («что тебе тут нравится больше всего?») → если ядро нравится, искать в нём решение → придать интересную форму. Если мысль обычная — подать необычно; если необычная — можно подать обычно.
- **Сделано хорошо, если:** у каждой идеи найдено ядро и усиленная форма; идеи не слиты в кучу; проблема под идеей подтверждена реальными цитатами, не притянута за уши. *Ошибки:* объединять идеи под «универсальным» зонтиком; обобщать вместо конкретики; навязывать аудитории проблему, которой в интервью не было; прятать готовое решение под вопросом.
- **Детальный материал:**
  - «Найди главную фишку (ядро) идеи и ищи новые формы для её максимального усиления и утрирования» (Method 2, докрутка).
  - «Объединение идей убивает одну из них или делает обе средними. Лучше взять одну идею и кристаллизовать её. Убить успеешь всегда» (Method 2, докрутка).
  - Метафора фонаря: «рассеянный свет фонаря помещаем в маленькую лазерную точку — конкретика даёт больше, решение понятнее, эффект лучше, чем когда про всё, а не про что» (Method 2, докрутка).
  - Метафора врача: не лечить «вообще плохо себя чувствует» — понять, что нога сломана, вправить кость. «Только разобравшись в каждой маленькой проблеме, увидишь одно большое решение» (Method 2, докрутка).
  - «Притягивание за уши»: проверять, есть ли проблема в реальных цитатах из исследования, или ты присвоил её аудитории (Method 2, докрутка).
  - **Главный вывод этапа** (Method 2): «Самая главная проблема не в том, что вы не умеете придумать, а в том, что не даёте идеям развиться. Берёте зёрнышко: "ну не, это не растение" — а чтобы оно стало растением, его надо поливать, а не складывать с другими в одно большое зёрнышко и не выкидывать».
  - **Ускорить с ИИ:** домашка-формат «30 идей через ИИ → отобрать 10» (Method 2); промпт-движок `01_GENERATION.md` сам прогоняет каждую идею через три вопроса (сервис / соцпроект / PR-заголовок) и ранжирует.

## Как вести человека по этапу  *(интерактив для ассистента)*

Принцип: человек **даёт** (направления/бриф/идеи) — ты **сам выдаёшь готовый артефакт**, он правит/утверждает, дальше. Рассуждение — про себя, в ответ только результат.

**Шаблон шага:** 1 строка «что делаем» → (если надо) попроси материал → выдай артефакт → «ок или поправить?» → дальше.

**Артефакт на каждом шаге:**
- **Ресёрч:** под выбранные направления сам набросай списки — мемы/приколы по теме + знаковые объекты региона + фактуру вокруг продукта → «что добавить?».
- **Бриф:** собери сам One-Page Brief — 6–8 жёлтых болей (дословные цитаты) + серые блоки (продукт / диджитал-сервисы / медиа / несвязанное) + три вопроса. Под активации — текстовый, под большие идеи — визуальный. «Что поменять?».
- **Индивидуальный шторминг:** дай инструкцию (час оффлайн, жёлтый × серый, одна мысль — один стикер) → если просит, нагенери сам идеи батчами через промпт-движок.
- **Командный шторминг:** напомни два правила (подготовка + ноль критики) + по одной идее по кругу, докрутка не критика.
- **Докрутка:** возьми идею → найди ядро → прогони через три вопроса → выдай усиленные формы → «какую берём?».

**Лекции:** на входе в этап и на релевантном шаге напомни «есть лекция по этому — дать?» (бриф/шторминг → «Одностраничный бриф»; докрутка → «Докручивание идей»; командная работа → «Командная сонастройка»).

**В конце:** собери ресёрч + бриф + список идей (ТОП после докрутки) в один документ — на этап 5 (отбор и финализация).
**Перед стартом:** 3 вопроса планирования + проверь, собран ли бриф (без него шторминг не начинаем).

> Примеры пока заглушка → опирайся на принципы лекций; появятся эталоны Дениса — в первую очередь на них.
