## DNS / домен

- **Домен:** `gotaddedvalue.com`
- **Регистратор:** **GoDaddy** (2026-05-18, подтверждено Денисом)
- **Целевой поддомен:** `method.gotaddedvalue.com` — будет указывать на Vercel deployment
- **Что нужно для подключения:** CNAME-запись `method` → `cname.vercel-dns.com` (точное значение Vercel выдаст при добавлении домена в проект). Доступы к GoDaddy-кабинету у Дениса; конкретный CNAME настраивается на шаге деплоя.
