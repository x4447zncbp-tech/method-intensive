# MATERIALS_INDEX

Карта доступных материалов в `/materials/` на момент **2026-05-18**. Источник для всех research-файлов (`/research/01_*.md` и далее). Citation rule из CLAUDE.md non-negotiable — каждое утверждение в research цитирует конкретный путь и фрагмент.

**Итого:** 77 файлов (без `.DS_Store` и `/materials/figma/`).

## Сводка по форматам и доступности

| Формат | Кол-во | Доступ к тексту |
|---|---|---|
| `.docx` | 40 | через `textutil -convert txt` (есть на этом mac, проверено) |
| `.jpg` | 10 | визуально через Read tool (мультимодально) |
| `.txt` | 7 | напрямую, plain text с **таймкодами вида `(0:00 - 0:06)`** |
| `.pdf` | 6 | через Read tool |
| `.xlsx` | 5 | требует python3 + openpyxl (python3 есть, openpyxl нужно поставить локально через `pip3 install --user openpyxl`) |
| `.pptx` | 5 | textutil не умеет; альтернатива: `python3 + python-pptx`, или конвертация через `qlmanage -t` (даст PNG-превью слайдов), или fallback на parallel `.txt`/`.pdf` где есть |
| `.html` | 3 | напрямую (текст) |
| `.mhtml` | 1 | MIME multipart, читается через python `email` модуль или просто `cat` (содержит inline HTML) |

**Аудио без транскрипта: нет.** Медиа-файлов (`.mp4`/`.mov`/`.mp3`/`.wav`) в материалах нет. Все исходные лекции уже представлены в виде транскриптов/конспектов/слайдов.

## Дубликаты, на которые стоит обратить внимание
